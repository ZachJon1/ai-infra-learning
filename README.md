# AI Infrastructure Learning Labs

Hands-on labs from my AI Infrastructure / ML Systems learning roadmap.

## Topics Covered

- Linux and systems fundamentals
- Docker and Docker Compose
- Kubernetes fundamentals
- Kubernetes networking
- Persistent storage
- ConfigMaps and Secrets
- Scheduling and resource management
- Health probes
- Autoscaling
- Helm
- RBAC and ServiceAccounts
- Jobs, CronJobs, init containers, and workload lifecycle

## Structure

Each `dayXX-*` directory contains hands-on exercises, Kubernetes manifests,
scripts, troubleshooting experiments, and notes from that day's topic.
